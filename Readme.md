# 手套佩戴监控检测系统

## 项目简介

手套佩戴监控检测系统是一个基于计算机视觉和深度学习的实时监控系统，主要用于检测工业环境中工作人员是否正确佩戴手套，以及是否存在摸头等危险行为。系统支持多种视频源输入，包括本地视频文件、RTSP网络摄像头和USB摄像头，并在检测到危险行为时自动发送邮件报警。

## 技术栈

- **前端框架**：PyQt6
- **后端框架**：Python 3.8+
- **深度学习框架**：PyTorch、Ultralytics YOLO
- **计算机视觉**：OpenCV
- **数据库**：SQLite
- **邮件服务**：SMTP

## 核心功能

### 1. 视频源管理

- **支持多种视频源**：本地文件、RTSP地址、本机摄像头
- **多场景管理**：可以创建和管理多个场景，每个场景包含多个视频源
- **视频源配置**：可以设置视频源名称、路径、类型和报警邮箱

### 2. 智能检测

- **手套检测**：检测工作人员是否佩戴手套，未佩戴时触发报警
- **头部检测**：检测工作人员是否有摸头动作，防止手部污染头部
- **区域检测**：可以设置特定区域，只在区域内进行检测
- **实时推理**：使用YOLO模型进行实时目标检测

### 3. 报警系统

- **邮件报警**：当检测到危险行为时，自动发送邮件报警
- **自定义收件人**：可以为每个视频源设置不同的报警邮箱
- **报警附件**：邮件中包含带标注的报警图片和原始图片

### 4. 系统监控

- **实时视频流**：实时显示视频流和检测结果
- **日志系统**：记录系统运行状态和报警信息
- **RTSP断流重连**：当RTSP流断开时，自动尝试重连

## 快速开始

### 环境要求

- Python 3.8 或更高版本
- PyTorch 1.8 或更高版本
- OpenCV 4.5 或更高版本
- PyQt6
- Ultralytics YOLO

### 安装步骤

1. **克隆项目**

```bash
git clone <项目地址>
cd GloveDetection
```

2. **安装依赖**

```bash
pip install -r requirements.txt
```

3. **配置模型**

将预训练的YOLO模型文件放置在以下目录：
- `model/glove/best.pt`：手套检测模型
- `model/head/best.pt`：头部检测模型

4. **配置邮箱**

编辑 `model/email_sender.py` 文件，配置发件人邮箱和授权码：

```python
self.smtp_server = "smtp.163.com"
self.smtp_port = 465
self.sender_email = "your_email@163.com"
self.sender_password = "your_authorization_code"
```

### 使用方法

1. **启动系统**

```bash
python main.py
```

2. **创建场景**

- 点击"添加场景"按钮
- 输入场景名称
- 点击"确定"按钮

3. **添加视频源**

- 选择一个场景
- 点击"添加视频源"按钮
- 填写视频源信息：
  - 名称：视频源的名称
  - 路径：视频文件路径、RTSP地址或摄像头ID
  - 类型：选择视频源类型（本地文件、RTSP地址或本机摄像头）
  - 报警邮箱：设置报警邮件的收件人邮箱
- 点击"确定"按钮

4. **开始检测**

- 在视频源列表中选择要检测的视频源
- 点击"开始检测"按钮
- 系统会创建检测线程并开始处理视频流
- 检测结果会显示在视频标签页中

5. **查看报警信息**

- 当检测到危险行为时，系统会在日志窗口中显示报警信息
- 同时会发送邮件报警到设置的邮箱
- 邮件中包含带标注的报警图片和原始图片

## 配置说明

### 默认配置

默认配置文件位于 `config/defaults.py`，包含以下配置：

- **启用的模型**：默认启用手套检测，禁用头部检测
- **模型置信度**：手套检测置信度为0.85，头部检测置信度为0.7
- **报警阈值**：手套检测连续2帧触发报警，头部检测连续10帧触发报警

### 区域配置

区域配置文件位于 `area/` 目录，用于定义不同视角的检测区域。系统会根据视频源路径自动推断视角，并加载对应的区域配置。

### 邮箱配置

邮箱配置位于 `model/email_sender.py`，包含以下配置：

- **SMTP服务器**：默认使用网易163邮箱的SMTP服务器
- **发件人邮箱**：需要配置有效的发件人邮箱
- **授权码**：需要配置邮箱的授权码（不是密码）
- **管理员邮箱**：默认的管理员邮箱列表，当视频源未设置报警邮箱时使用

## 常见问题

### 1. 视频流无法连接

- 检查视频源路径是否正确
- 对于RTSP流，检查网络连接和摄像头状态
- 对于USB摄像头，检查摄像头是否正确连接

### 2. 检测效果不佳

- 调整模型置信度和报警阈值
- 确保视频源光线充足
- 检查模型文件是否正确放置

### 3. 邮件发送失败

- 检查SMTP服务器配置
- 检查发件人邮箱和授权码
- 检查网络连接
- 检查收件人邮箱是否正确

### 4. 系统性能问题

- 对于低配置设备，建议降低视频分辨率
- 调整检测帧率，默认为30fps
- 只启用必要的模型

## 故障排除

### 日志查看

系统会在控制台和日志窗口中显示运行状态和错误信息。当遇到问题时，可以查看这些日志信息来定位问题。

### 常见错误

1. **SMTP认证失败**：检查邮箱地址和授权码是否正确
2. **模型加载失败**：检查模型文件是否存在且格式正确
3. **视频流连接失败**：检查视频源路径和网络连接
4. **数据库操作失败**：检查数据库文件权限

## 系统维护

### 模型更新

当需要更新模型时，只需将新的模型文件替换到对应的目录即可：
- 手套检测模型：`model/glove/best.pt`
- 头部检测模型：`model/head/best.pt`

### 数据库备份

数据库文件位于 `model/monitor.db`，建议定期备份此文件以防止数据丢失。

### 系统更新

当系统代码更新时，只需替换对应的文件即可，无需重新配置。
